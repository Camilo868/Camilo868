DETROIT-PM LANDING PAGE

My project after about 3 weeks of learning HTML and CSS. It’s a landing page for a rock band called "DETROIT-PM." I'm really excited because it’s the first time I managed to make a site look organized and make it work on mobile!

For this project, I focused on understanding how to structure a page and how to style it without getting too overwhelmed. I used semantic tags like header, main, section, and footer to keep the code clean. I also built a "Hero" section with an image and an overlay to give it that professional rock star look as soon as you enter.

The design was the most fun part. I used Flexbox for the navigation menu to get the items to align side-by-side easily. I also tried out CSS Grid for the Media section to organize the photos into a neat 2-column layout. One of the coolest things I learned was Responsive Design; I used media queries so that when you view the page on a phone, the photo grid stacks into a single column so it doesn't look squashed. I even added a hover effect to the menu links so they turn red and grow slightly when you point at them.

I still have a lot to learn, and I kept some parts simple for now while I get better at styling, but I'm really happy with the dark theme and how the sections turned out. Keep on coding!
